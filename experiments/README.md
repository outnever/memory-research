# Experiments

One directory per experiment: `YYYYMMDD-HHMMSS-slug/`.

Each contains enough to rerun it — the data or a script that fetches it, the exact
commands, and a `RESULT.md` with the outcome.

A `RESULT.md` reports: the question, the setup, the outcome, the context cost if
relevant, what is still unknown, and any speculation clearly labelled as such.

Negative results are kept. They are results.
